# asip-dev-practice

ASIP Software Development readiness practice.

I am Abraham Addisu. This repo is my own sample work for the 48 hour Git and GitHub check. It is not Labari source code. It does not use real users, passwords, or company files.

## What I worked on

I made a small dummy reading list in JavaScript.

It stores a few fake books and can:

- list all dummy books
- show only books that are marked available
- filter by language (en or am)

I used this to practice:

- a personal GitHub repo
- a feature branch (not main)
- a clear commit
- a short README

## Why this sample

I read books from mixed places today. For this exercise I wanted a tiny, honest example: a list, a filter, dummy data. Nothing that looks like a full product.

## How to run

You need Node.js.

```
node src/dummyLibrary.js
```

## Repo notes

- Branch I used: `practice/dummy-reading-list`
- Data in `src/dummyLibrary.js` is fake. Titles and names are made up.
- No Labari files. No API keys. No private sheets.
